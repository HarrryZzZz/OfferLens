# OfferLens

OfferLens 是一个中文优先的 Chrome 个人职业档案插件。档案保存在插件自身的 IndexedDB 中；使用可选的 AI 岗位匹配时，用户选中的内容和岗位描述会发送给 OpenAI。

## 安装与运行

需要 Node.js 20.19+、22.13+ 或更高受支持版本。

```bash
npm install
npm run build
```

打开 Chrome 的 `chrome://extensions`，启用右上角「开发者模式」，点击「加载已解压的扩展程序」，选择本项目的 `dist` 目录。点击插件图标，在弹窗中选择「打开个人档案」。更新代码并重新构建后，在扩展程序页面点击刷新。

## 使用

- 在侧边栏选择分类，新增记录或编辑现有记录；点击「保存更改」后写入本地，取消会放弃草稿。点击记录可展开或折叠。
- 编辑表单中可以修改预设字段的显示名称，也可以移除不需要的预设字段；移除只影响当前记录，原内容保留并可在「已移除的字段」中恢复。自定义字段可以添加、改名、设置类型和选项、排序或删除。类型转换仅在现有值可安全保留时允许。多选及单选的选项每行一个；删除已选选项前先清除相应选择。
- 工作成果可以在量化成果字段中按行记录。技能和项目等关联以文本记录，删除一条记录不会留下内部引用。
- 在「设置与备份」导出 JSON。恢复时先选择文件、查看分类数量，再确认替换。导入会严格检查结构，并在事务内替换全部数据；不支持合并。
- 数据仅在当前浏览器的插件存储中。卸载扩展或清除插件数据可能永久删除数据；请定期导出并妥善保管备份。备份包含个人信息，不要放入不可信的位置。

## 开发与测试

```bash
npm run dev
npm test
npm run build
```

`src/config.ts` 定义分类和预设字段；`src/data.ts` 负责类型、校验、IndexedDB 和备份事务；`src/main.tsx` 是管理页面；`src/popup.tsx` 是插件弹窗；`public/manifest.json` 是 Manifest V3 清单。`tests/data.test.ts` 覆盖核心存储、动态字段及备份。

当前备份格式为 `schemaVersion: 1`。未来修改格式时需要增加显式迁移；本地档案管理仍可离线使用；AI 岗位匹配需要用户自行配置 OpenAI API。

## 本地简历解析

在管理页面选择「简历解析」（或从「简历管理」进入），上传文字型 PDF、DOCX、UTF-8 TXT，或直接粘贴文本。文件上限 10 MB，PDF 最多 50 页。点击「识别并预览」后，可逐条修改、勾选或手动补充基本信息、教育、工作、项目和技能；确认前不会写入档案。也可选择将提取后的全文另存到「简历管理」。

解析完全在浏览器本地完成，不调用 AI 或上传简历。规则识别可能漏掉内容或将经历划分错误，请对照原文核对。只有简历中明确包含完整年月日且日期有效时，才会填入日期字段；只有年月的时间保留在识别来源/说明中，供手动处理。多栏 PDF、表格和特殊排版的文本顺序可能不准确。扫描件、图片、加密文件和旧版 `.doc` 不受支持；如果 PDF 某页无法提取文字，会提示检查原文件。

导入只新增勾选记录，基本信息只填空字段，不覆盖已有内容或隐藏字段。插件根据学校、公司、项目或技能名称提示可能重复；提示不代表一定是同一记录，需自行判断。写入在同一本地事务中完成，发生冲突或校验失败时不会部分导入。

## 侧边栏快捷填写

重新构建并在扩展程序页面刷新 OfferLens 后，打开招聘网站，刷新该网页，然后点击插件图标并选择「打开快捷填写侧边栏」。先在网页中点击目标输入框，再在侧边栏**左键**点击字段名称即可填写；**右键**点击字段名称会复制字段内容。侧边栏按分类折叠显示字段名；灰色字段表示尚未填写。多条经历以学校、公司或项目等名称区分，可在管理页面维护内容。

侧边栏需要 Chrome 116 或更新版本。插件使用 `sidePanel` 打开侧边栏、`clipboardWrite` 完成复制、`storage` 暂存当前网页中最后选择的输入框所在框架，并请求 HTTP/HTTPS 网页访问权限，以便识别用户选中的输入框和写入用户主动选择的字段。快捷填写功能不会读取网页表单内容。网页会收到被用户主动填写的内容；提交表单由用户自己决定。使用 AI 岗位匹配时，用户勾选的档案内容会发送给 OpenAI。

Chrome 内部页面、浏览器扩展页面及部分受保护页面不允许扩展填写；个别网站的自定义控件或特殊日期格式也可能不兼容。下拉框仅在选项的文字或值完全匹配时填写；不支持密码、文件上传和多选控件。遇到不兼容时，可右键复制后手动粘贴。安装或更新扩展后，已经打开的目标网页需要刷新，才能启用填写脚本。

## AI 岗位匹配

1. 在 Chrome 扩展程序页面重新加载插件并接受新增的 OpenAI API 域名访问权限。扩展更新完成后打开 OfferLens 管理页面。
2. 打开「设置与备份」中的「AI 服务设置」，填写自己的 OpenAI API 密钥和可用模型名称，保存。默认使用 `gpt-4o-mini`；可修改为账户可用且支持 Responses API 与结构化输出的模型。ChatGPT 订阅不等于 API 额度，API 使用量可能收费。
3. 在「设置与备份 → 岗位匹配设置」选择简洁或详细模式，并勾选可发送的档案字段。保存后，新填写的字段默认不发送，需在这里勾选。然后在扩展侧边栏点击「岗位匹配」粘贴 JD 并开始分析，选定内容与 JD 会通过 HTTPS 发送到 OpenAI。
4. 简洁模式显示综合匹配度和简短说明；详细模式还显示各维度匹配度及证据。简洁模式请求更精简的输出，通常可以减少输出 token，但输入和实际用量仍取决于模型和文本。匹配度按岗位要求加权估算，必需项为加分项的两倍；未匹配表示所选档案中没有找到对应证据，不代表一定不具备相关能力。引用编号不存在或匹配项缺少证据时，该要求会单独标记为证据异常，不纳入评分；页面会标出评分覆盖的要求数量。旧分析记录仍可查看，但由于缺少新评分所需分类，需使用原 JD 重新分析才能获得百分比。结果、岗位描述及所选证据自动保存在当前浏览器，可在分析记录中删除。当前分析记录不包含在档案 JSON 备份中，导入或删除档案也不会自动删除分析记录。

「基本信息」（含自定义字段）和「简历管理」不会进入 AI 分析。其他分类的自由文本、自定义字段以及岗位描述仍可能含个人信息，请发送前自行检查。隐藏的预设字段不会发送。分析结果是模型给出的参考意见，不是录用概率，可能存在错误。

API 密钥保存在 Chrome 扩展本地存储中，不包含在档案备份或历史记录里；本机用户或恶意软件仍可能读取密钥。建议使用独立密钥并设置用量上限，可在 AI 设置中删除。当前只支持 OpenAI 官方 Responses API，模型名称可修改；`src/ai/core.ts` 提供服务商接口以便未来加入 DeepSeek 等适配器，不代表这些服务已兼容。`store: false` 用于请求，但服务商的日志与留存政策仍然适用。
